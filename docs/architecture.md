# 专家模型增量更新智能体架构

## 目标

系统接收上游交付的专业小模型、构造配置、原权重和新数据，在不依赖原训练工程的前提下恢复模型实例、收集决策证据、选择合适的增量方法，并最终交付新权重、效果对比和可追溯记录。

使用自己的更新方法不等于可以改变原任务目标。优化器、学习率和训练组织可以重新设计；核心任务、主损失含义、输入输出语义和需要保留的能力必须作为更新约束。

## 固定前置流程

```text
用户请求
→ TaskInput v0.3 草案
→ 人工确认
→ 模型文件/构造配置/checkpoint/新数据预检
→ 安全解析构造配置
→ 安全检查 checkpoint 结构
→ 静态验证唯一模型交付
→ 本地子进程创建模型并严格加载权重
→ 模型结构与可训练性报告
→ 更新决策
```

上游不需要提供原训练循环、优化器、学习率、训练轮数或完整项目源码，但必须提供：

- 包含声明模型类的模型文件；
- 符合固定契约的构造配置；
- 与模型结构对应的 checkpoint。

系统不搜索完整项目、不枚举模型候选，也不从权重形状猜测完整构造配置。

## 前置工具

### 任务受理

- validate_task_input：校验 TaskInput v0.3、固定必答问题和确认门槛；
- preflight_task_assets：只检查四个声明资产的存在性、类型和可读性。

### 声明资产检查

- inspect_model_config：把构造配置作为数据安全解析；
- inspect_model_checkpoint：用 weights_only 模式读取 checkpoint 结构与张量元数据。

两项检查都不导入模型文件，也不证明模型与权重兼容。

### 模型交付验证

validate_model_delivery 绑定已确认任务、预检和两项检查报告，并验证：

- 构造配置符合固定 Schema；
- 模型文件中存在唯一声明类；
- 构造参数与静态签名一致；
- 配置声明的 state_dict 路径在 checkpoint 证据中存在；
- 三个模型资产在检查后没有变化。

成功后输出唯一 validated_load_plan，不存在候选选择阶段。

### 加载与结构分析

- load_validated_model：创建模型实例并执行 strict checkpoint 加载；
- analyze_validated_model_structure：在同一 worker 内加载模型后分析注册模块、参数、缓冲区、共享关系和可训练参数。

只有 strict=true、missing_keys 为空、unexpected_keys 为空，才能声称权重完整恢复。第一版不执行 forward，因此结构报告不证明输入输出运行正确。

## 更新决策与执行

更新决策 Agent 基于已确认 TaskInput、模型结构、可训练性、数据证据和方法卡回答：

1. 本次更新希望逼近什么目标；
2. 哪些任务语义和旧能力不能改变；
3. 哪种方法用什么信息近似旧数据贡献；
4. 方法前提是否满足；
5. 属于精确增量、近似增量还是新目标适配。

更新执行 Agent 不修改上游原训练项目。它在受控工作区围绕已恢复模型建立本次更新所需的数据适配、训练、评估和产物保存代码。原模型文件、配置和 checkpoint 始终只读，新权重写入独立输出位置。

## Agent 分工

| 环节 | 更新决策 Agent | 更新执行 Agent | 独立审阅 Agent |
| --- | --- | --- | --- |
| 核心问题 | 用什么方法，为什么，前提是什么 | 怎样围绕交付模型实现、训练和评估 | 证据是否可信并满足验收 |
| 输入 | TaskInput、模型/数据证据、方法卡 | 已批准 UpdatePlan、交付模型、新数据 | 任务、计划、代码、运行记录、权重、指标 |
| 输出 | UpdatePlan | ExecutionResult 或重规划请求 | ReviewResult |
| 禁止 | 猜测缺失构造信息、擅改任务目标 | 覆盖原资产、前提不成立仍强行训练 | 修改实现、自行放宽标准 |

## Harness 边界

Pi 负责模型、Tool Call、Tool Result 和上下文循环，不替代业务状态机或验收。当前模型加载使用本地 Python 子进程，但没有操作系统级隔离；导入外部模型文件仍可能产生副作用，报告必须如实保留这一边界。

## 当前方法包

incremental_ridge_closed_form v0.1 只适用于固定平方误差加 L2 正则、特征与目标契约不变、旧充分统计量可用的仿射线性回归。它不能用于只有神经网络权重的任意模型，也不能把原 MAE 目标改成最小二乘后仍声称与原目标下全量训练等价。
