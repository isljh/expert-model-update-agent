# 模型创建方案静态验证工具 v0

**状态：** 创建方案验证、实例化、checkpoint 加载、结构解析和正式报告第一版已贯通；剩余工作以运行边界和跨项目兼容验收为主，不继续无依据扩张静态验证范围。

## 目标

实现一个确定性工具，只验证项目理解 Agent 提出的最小模型创建方案，并在条件满足时生成安全实例化工具可读取的 `validated_instantiation_plan`。

## 已确定边界

- 不重新理解项目；
- 不发现或推荐模型候选；
- 不执行目标项目；
- 不创建模型实例；
- 不打开或解析 checkpoint，不把加载指令通过解释为权重加载成功；
- 多个方案通过时不默认选择第一个；
- 只读取资产预检授权的目标项目源码；checkpoint 仅做路径和加载指令绑定。

## 已完成的行为核对

- ResNet 工厂加 `DataParallel` 的两步方案能够通过 callable、包装依赖、源码锚点、运行时对象和 `$.module` 目标路径检查；
- 同时提交两个都成立的 ResNet 工厂方案时，工具返回 `ambiguous`，不产生可执行计划；
- 即使 proposal 声明 checkpoint，静态验证器也只输出已绑定的加载指令，不读取文件内容；结构证据必须来自上游专用 Inspector。

开发测试输入、完整运行输出和参考答案不写入 Pi 正式工作区。
