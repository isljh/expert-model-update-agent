# TaskInput v0.3 实现记录

## 目标

把用户请求整理为可校验、可确认的 TaskInput，并把模型文件、构造配置、checkpoint 和新数据绑定到只读资产预检。

## 已完成

- [x] 定义 TaskInput v0.3 Schema；
- [x] 保留用户原文、更新目标、数据用途、保留能力和成功期望；
- [x] 将模型文件、构造配置和 checkpoint 设为三个独立必答资产；
- [x] 删除目标项目位置和 checkpoint 发现授权；
- [x] 更新固定必答问题映射；
- [x] 实现 draft 与 confirmed 两种校验门槛；
- [x] 实现与任务、版本和资产摘要绑定的预检；
- [x] 更新 task-intake Skill 和 Pi 工具描述；
- [x] 增加三个模型资产的单元测试。

## 边界

任务受理不读取资产内容，不导入模型，不从权重猜构造参数，不选择增量学习方法。确认后才进入配置检查、checkpoint 检查和模型交付验证。
